# あとで見つかる（v0.3）

保育園の連絡帳・お知らせ・チラシ・写真を1か所にためて、あとから日付とキーワードで探せるWebアプリ（iPhoneのSafari向け）。

- 公開URL: https://ccwatode.github.io/atode-mitsukaru/
- 取り込み・検索・保存はすべて端末内（ブラウザのIndexedDB）で行い、外部サーバーやAI APIには送信しない
- このリポジトリにはアプリ本体とソースのみを置く。連絡帳データ・写真・サンプルPDFは含めない

## iPhoneでの使い方

1. Safariで公開URLを開く →共有ボタン→「ホーム画面に追加」
2. ホーム画面のアイコンから起動し、下の「＋」から追加
   - 写真：写真ライブラリから複数まとめて（撮影日を自動入力）
   - チラシ・配布資料：スクリーンショット・写真・PDF
   - お知らせの文章：コピーした文章を貼り付け（タイトルと日付を自動入力）
   - 連絡帳PDF：はいチーズ！ノートの画面をPDF保存したもの（複数選択可）
   - メモ
3. 「データ」→「バックアップを作成」→「ファイルに保存」→ iCloud Drive を選ぶ
   - 機種変更や削除のあとは「バックアップから復元」。今のデータは消えず、同じ記録は重複しない

## v0.3 の主な変更

| 区分 | 内容 |
|---|---|
| 共通受け箱 | 連絡帳／お知らせ／チラシ・資料／写真／メモを同じ時系列で表示。行事・子どもで整理 |
| 写真 | 表示用（長辺2560px）とサムネイル（400px）を保存。原本保存は設定で選択 |
| 検索 | 連絡帳・お知らせ・チラシの本文、画像内の文字（手入力）、ファイル名を横断検索 |
| バックアップ | 画像・元PDFを含む1つのZIP。復元は追加のみで上書きしない。最終バックアップ日時を表示 |
| PDF | PDFの長さ上限（約14400pt）で切れたことを検出し、続きのPDFの作り方を案内。複数PDFの一括取り込み |
| UI | タブ（ホーム・検索・＋・写真・データ）、月ごとのタイムライン、未取得日のまとめ表示、ダークモード |
| 移行 | v0.2 のデータはそのまま残る（DBに保存場所を追加するだけで、既存の記録は書き換えない） |

## 開発

`source/` にソースがある。npmレジストリに頼らず esbuild で直接ビルドしている。

```
cd source
npm install           # esbuild / react / react-dom / pdfjs-dist / typescript
node build.mjs        # dist/ に出力
node --test test/*.test.ts
npx tsc -p tsconfig.json --noEmit
```

新しい依存ライブラリは追加していない（ZIP・EXIF読み取り・画像縮小は自前の実装とブラウザ標準機能）。

## プライバシー

- 子どもの個人情報・写真・連絡帳PDFはこのリポジトリに置かない（`.gitignore` で除外）
- アプリは外部への通信をしない（初回読み込みとService Workerによるキャッシュのみ）
- はいチーズ！への自動ログイン・自動取得・非公開APIの利用はしていない。取り込みは利用者が保存したPDF・画像・文章のみ
